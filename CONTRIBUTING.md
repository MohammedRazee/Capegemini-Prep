# Contributing

This repo stays useful only if each batch updates it. Thank you for helping.

## Ways to contribute

1. **Share your interview experience.** Copy [`experiences/TEMPLATE.md`](experiences/TEMPLATE.md), rename it to `YYYY-MM-yourname.md`, fill it in, and open a pull request.
2. **Report a broken or outdated link.** Open an issue with the link and where you found it.
3. **Suggest a better resource.** Open an issue explaining *why* it's better than what's listed. We keep lists short on purpose.
4. **Fix a mistake.** Edit the file and open a pull request.

## Rules

- **Don't share confidential material.** No screenshots of the actual test, no copied questions, and no files marked "Company Confidential". Describe *topics and patterns* instead.
- **Keep it curated.** Every new link needs a reason. Mark it 🟢 (essential) or 🔵 (optional), and 💰 if paid.
- **Be honest.** If something is reported but not confirmed, say so.
- Add a line to [CHANGELOG.md](CHANGELOG.md) for any significant change.

## No GitHub experience?

Send your experience or correction to the Placement Cell faculty coordinator and they'll add it for you.
