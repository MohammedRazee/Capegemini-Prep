# Stage 2 — Technical Module

[← Back to stages](../README.md)

> **Format:** 2 sections × 20 MCQs, ~45 minutes total. That's about **1 minute per question**.

| Section 1: **AI Literacy** (20 Q) | Section 2: **Technical** (20 Q) |
|---|---|
| AI foundations & Generative AI (foundation models, LLMs, capabilities & limits) | Programming logic & problem solving (data types, I/O, pseudocode, debugging) |
| Prompt engineering & AI productivity (prompt structure, context, ChatGPT, GitHub Copilot) | DSA (arrays, strings, hashing, searching, sorting, time/space complexity) |
| Advanced AI systems (RAG, agentic AI, AI agents, multi-step workflows) | Software engineering (OOP, DBMS, SQL, REST APIs, HTTP methods, Git) |
| Responsible AI & evaluation (output validation, bias, responsible practices) | Modern engineering (client-server, cloud, API keys vs tokens, networking, cybersecurity, Agile, DevOps, Docker) |

## ⏱️ Exam strategy
- **1 minute per question.** If you're stuck after 60 seconds, mark it and move on.
- In AI questions, look for the **responsible** answer. Options like "always trust the AI output" or "AI never makes mistakes" are almost always wrong.
- In pseudocode questions, **trace on paper** with a small table of variable values.
