# Round 1 — The Exceller Assessment (Stages 1–5)

[← Back to main README](../README.md)

## The five stages at a glance

| # | Stage | Format | Time | What decides your score | Prep folder |
|---|---|---|---|---|---|
| 1 | **English Communication** | Listening, speaking, reading, writing | ~30 min (reported) | Clear, steady speech; comprehension; grammar | [stage-1-english](stage-1-english/) |
| 2 | **Technical Module** | 2 sections × 20 MCQs (AI Literacy + Technical) | ~45 min | Concept clarity, speed | [stage-2-technical-module](stage-2-technical-module/) |
| 3 | **Debugging** | 1 problem, fix the buggy code | ~20 min | Finding *all* the bugs and handling edge cases | [stage-3-debugging](stage-3-debugging/) |
| 4 | **AI-Assisted Coding** | Solve a problem with an in-test AI assistant | varies | **How** you prompt and review, not just the output | [stage-4-ai-assisted-coding](stage-4-ai-assisted-coding/) |
| 5 | **Cognitive** | Motion Challenge (6 min), Grid Challenge (12 min), Logical Reasoning (~25 min), Behavioural (25 min) | ~70 min | Planning, working memory, logic, consistency | [stage-5-cognitive](stage-5-cognitive/) |

Timings are from Capgemini's candidate briefing and may differ slightly on the day.

## Rules that matter

- **Some stages are eliminatory.** You must clear each one to move on, so don't neglect any stage.
- **Stages 2–5 are attempted in one go** (if you clear the eliminatory rounds). Plan for ~2.5 hours of focus. Have water nearby and use the bathroom before you start.
- **Read the instructions before each section starts.** Many candidates lose time reading game rules after the timer has begun.
- **Malpractice = disqualification.** No phones, no other tools, no talking.

## Packages (candidate-reported, not official)

Prep sites report three offer tiers, decided mainly by coding performance:

| Tier | Reported CTC | Reported condition |
|---|---|---|
| Analyst | ~4.25 LPA | Clears the process |
| Analyst Star | ~5.75 LPA | Strong coding performance |
| Senior Analyst | ~7.50 LPA | Top coding performance |

Treat these as indicative only. The point is that **coding and debugging skill can move you up a tier**.

## Where people fail (and how not to)

| Pitfall | Fix |
|---|---|
| Preparing only from old "pseudocode + quant" papers | Use them for practice volume, but cover AI literacy, debugging and games too |
| Python-only coder meets a C/C++/Java debugging question | Spend 2 hours reading Java syntax: loops, arrays, `String`, `HashMap` |
| Typing "write the code" into the AI assistant | Use the [4-step template](stage-4-ai-assisted-coding/README.md#the-4-step-prompt-template) |
| Bad mic or noisy room in the speaking test | Headset + quiet room; test your recording the day before |
| Faking answers in the personality test | Answer honestly and consistently; it's adaptive and spots contradictions |
