## 📄 Resume (one page, ATS-friendly)

| | Resource | Cost | What to do |
|---|---|---|---|
| 🟢 | [Jake's Resume (Overleaf)](https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs) | Free | Open → "Open as template" → fill it in. Single column, parses cleanly. |
| 🟢 | [Tech Interview Handbook — Resume](https://www.techinterviewhandbook.org/resume/) | Free | Read the bullet-writing rules: *action verb + what you did + result/number*. |
| 🔵 | [GitHub profile README guide](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme) | Free | Pin your 2–3 best repos, each with its own README. |

**Order of sections:** Education → Skills → Projects (2–3) → Certifications / Internships → Achievements.

**Capgemini-specific resume tips:**
- Add an **"AI tools" line** under Skills (e.g., *ChatGPT, GitHub Copilot, prompt engineering*). Capgemini now tests AI literacy, and interviewers may ask about it.
- List **Java or C/C++** if you can defend it. Debugging is in these languages.
- For every project, be ready to explain **what you built, why that stack, one bug you fixed**.

**Avoid:** two-column Canva designs, 15 skills you can't defend, "MS Office" as a skill, photos, and projects copied from YouTube that you can't explain.

## 🖥️ Test-day setup

- [ ] Laptop (not a phone), charged, with the charger plugged in
- [ ] Latest Chrome/Edge, pop-up blocker off for the test site, extensions disabled
- [ ] **Headset with a mic.** Test it by recording yourself.
- [ ] Webcam working, good lighting on your face (proctored)
- [ ] Quiet room for **~2.5 hours** (Stages 2–5 run in one go)
- [ ] Mobile hotspot ready as backup internet
- [ ] Nothing on the desk except what's allowed. **No phone in reach.**

> 🚫 **Rules from Capgemini:** no phones, no external tools, no discussing with others. Malpractice = disqualification.
