# Changelog

## October 2026 — First release
- Created the repo for the **Capgemini Exceller 2026** drive (Presidency University MCA 2027).
- Structure follows the new 5-stage Exceller assessment, then Technical and HR interviews.
- Added original practice material: AI literacy cheat sheet + 15 MCQs, CS one-liners, 8 pseudocode questions, **10 tested debugging problems** (C/Java), and the 4-step AI prompt template.

### Resource changes noted at release
- **Pramp** now runs through **Aced (formerly Exponent)**: https://www.tryexponent.com/practice
- **Google Interview Warmup** has been retired. Removed.
- **Striver's A2Z sheet** moved to https://takeuforward.org/prep-hub/strivers-a2z-dsa-sheet
- **DeepLearning.AI** short-course certificates now need a paid Pro plan; videos are still free.
- Many prep sites still describe the **old** Capgemini pattern (pseudocode + quant + 2 coding questions). Use them for practice questions, not for the test structure.
